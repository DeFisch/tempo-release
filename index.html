Too many robotics papers gravitate toward tabletop tasks that generalists like ChatGPT Astra can already do zero-shot. Twitter main (anchor tweet)

Too many robot manipulation tasks are static… ahem… boring! 🙈 Tabletop tasks are now solvable zero-shots by generalists like ChatGPT Astra. Time to move on! We explore dynamic manipulation, where VLA must react as humans move. We pinpoint what they're missing, and fix it 🧵👇

Thread 1: Reason #1, object motion

Why do VLAs break the moment the world moves? 🤔 Reason #1: A VLA acts on one frame, and one frame can't tell you how the scene is moving. So it reaches for where the object was. Fix #1: We introduce a motion cue that informs the policy of how the scene is moving.

Thread 2: Reason #2, state aliasing

Reason #2: In dynamic tasks, we frequently encounter visually similar observations from entirely different phases of the task. Traditional VLA doesn’t know how to disentangle it. Fix #2: We introduce a compact summary of recent proprio history that helps policy tell its phase.

Thread 3: temporal context, not speed

For dynamic tasks, most people have worked on speeding up VLA’s inference delay; we show that this isn’t the case. What’s missing is temporal context. TEMPO is plug-and-play: No architectural changes; minimal latency.

Thread 4: four dynamic tasks

We test on four dynamic tasks where human introduces constant movements into the environment, as our day-to-day life environment will be.
